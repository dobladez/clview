# Spec implement

Read these, in order, then follow the recipe:

1. [`../spec-shared/conventions.md`](../spec-shared/conventions.md): what every `spec-*` skill shares.
2. `docs/specs/project.md`: this project's commands, code and conventions.
3. [The recipe](references/recipe.md), all of it, before acting.

**Invariant:** keep the status honest. Never tick a Tasks or Done item without checking it, and
never mark the spec `Done` while an item is open.
